## How it was made

Everything is generated by [`build/make_demo.py`](build/make_demo.py), so the video can be rebuilt
after any change:

* **Voice:** macOS text-to-speech, voice **Aman (English (India))**, falling back to *Rishi*. Each
  sentence is synthesised separately, so the subtitles have exact timings. A small pronunciation
  table makes "Qwen" sound like *Kwen*, "TF-IDF" letter by letter, and so on. The written forms stay
  in the subtitles.
* **Slides:** HTML at 1920×1080, rendered to PNG with Playwright. They use the same colour palette
  as the charts in [`results/`](../results/).
* **Screen footage:** the real LLaMA Board browser sessions recorded during Phase 3
  ([`recordings/llamaboard_train_session.mp4`](recordings/llamaboard_train_session.mp4), 25 min, and
  [`recordings/llamaboard_chat_session.mp4`](recordings/llamaboard_chat_session.mp4), 44 s).
* **Assembly:** ffmpeg from the `imageio-ffmpeg` package (no system install), H.264 + AAC.

The full narration is in [`narration_script.md`](narration_script.md).

```bash
python demo/build/make_demo.py      # ≈ 2 min on an M2; needs macOS (say) + playwright chromium
```
